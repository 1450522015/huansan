# 战局V2 重构文档

## 架构设计

BattlePageV2.vue
```
├── composables/
│   ├── useBattleState.js      ← 角色数据同步、状态管理
│   ├── useBattleSocket.js     ← Socket 事件、重连、聊天
│   ├── useBattleAction.js     ← 出招、目标选择、提交
│   ├── useBattleTimer.js      ← 倒计时、回合管理、速度控制
│   └── useBattleEvent.js      ← 战况事件解析 + 渲染编排
│
├── components/
│   ├── BattleTop.vue          ← 顶部状态栏
│   ├── WujiangCard.vue        ← 武将组件（名称/图案/血条/光环/特效）
│   ├── ZuoqiCard.vue          ← 坐骑组件
│   ├── BattleBottom.vue       ← 底部操作栏（聊天/调试）
│
└── skills/
    ├── 舍命一击.js
    ├── 力劈华山.js
    ├── 排山倒海.js
    ├── 固若金汤.js
    ├── 凌波微步.js
    ├── 画地为牢.js
    ├── 趁火打劫.js
    ├── 四面楚歌.js
    ├── 金蝉脱壳.js
    ├── 暗渡陈仓.js
    ├── 呼风唤雨.js
    ├── 妖火燎原.js
    ├── 五雷轰顶.js
    ├── 巫蛊极毒.js
    └── 毁天灭地.js
```
