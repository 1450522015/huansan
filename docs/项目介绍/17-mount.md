## 成长值

成长值 = 1 + 转世次数 × 0.1（例如 3 转为 1.3）。下文记为 **G**。

实现：`common/gameCatalog.js` 中 `坐骑战斗加成(种类, 等级, 转数)`，等级 **L** clamp 在 1～160；仅战斗回合生效、不进面板合并的项见同文件 `坐骑战斗阶段占位`。

## 气血 / 精力 / 攻击 / 速度类

以下与 `docs/私有文档/坐骑.md` 一致。记号：**core** = `50 + (L×0.2+7)×L×G`；**重攻段** = `100 + (L×0.2+14)×L×G`（战马、逍遥灰影的 **攻击** 即 **core** 本体，非 `core×5`）。

| 坐骑 | 加成 |
|------|------|
| 战马 | 攻击：`50 + (L×0.2+7)×L×G`（即 **core**）；速度：`(L−50)×G` |
| 乌云踏雪 | 气血：`core×5`；攻击：重攻段 |
| 绝影 | 气血：`core×5`；精力：`100 + (L×0.2+14)×L×G×5` |
| 里飞沙 | 攻击：重攻段；速度：`L×G` |
| 夜照玉狮子 | 气血：`core×5`；速度：`L×G` |
| 的卢 | 气血：`100 + (L×0.2+14)×L×G×5`；精力：`50 + (L×0.2+7)×L×G×5` |
| 爪黄飞电 | 精力：`200 + (L×0.2+28)×L×G×5` |
| 燎原火 | 攻击：`200 + (L×0.2+28)×L×G` |
| 赤兔胭脂兽 | 速度：`(50 + L) × G` |

数值在代码中按字段 **四舍五入取整** 后参与战斗合并。

## 抗性坐骑（与并存气血 / 精力 / 攻击 / 速度）

下列坐骑除抗性外，另有与私有文档一致的 **基础战斗字段**，一并经 `坐骑战斗加成` 写入并与装备等 **同名相加**。

| 坐骑 | 公式 |
|------|------|
| 逍遥灰影 | 攻击：**core**；抗物理：`10 + 0.1×L`；抗玄击：`0.05×L` |
| 天马白鸽 | 精力：`core×5`；抗围困：`5 + 0.1×L`；抗扰乱、`抗封锁`：各 `0.05×L` |
| 如山乌孙 | 精力：`core×5`；抗围困、`抗封锁`：各 `0.05×L`；抗扰乱：`5 + 0.1×L` |
| 百里惊帆 | 精力：`core×5`；抗围困、`抗扰乱`：各 `0.05×L`；抗封锁：`5 + 0.1×L` |
| 嘶啸奔雷 | 速度：`L×G`；抗落雷：`5 + 0.1×L`；抗风沙、抗妖火：各 `0.05×L` |
| 不死黑云 | 气血：`core×5`；抗毒术：`5 + 0.1×L`；抗风沙、抗妖火：各 `0.05×L` |

## 南蛮象骑 / 攻城锤 / 司南车 / 诸葛连弩 / 木牛流马（面板可合并项）

与 `docs/私有文档/坐骑.md` 一致；数值 **四舍五入取整** 后写入 `坐骑战斗加成` 返回值，经 `attrCalculator` 与装备等 **同名相加**。

| 坐骑 | 加成 |
|------|------|
| 南蛮象骑 | 气血：`150 + (L×0.2+21)×L×G×5`；速度：`(L−50)×G` |
| 攻城锤 | 攻击：`100 + (L×0.2+14)×L×G`；穿透率：`0.1×L` |
| 司南车 | 气血、精力：各 `core×5` |
| 诸葛连弩 | 精力：`100 + (L×0.2+14)×L×G×5`；速度：`(L−50)×G`；法穿率：`0.1×L` |
| 木牛流马 | 气血、精力：各 `core×5` |

## 战斗阶段占位（不进面板合并）

下列效果 **不在** `坐骑战斗加成` 中返回，由 `坐骑战斗阶段占位(种类, 等级, 转数)` 提供，供 **配置页文案** 与未来 **战斗回合逻辑** 读取；当前 **不参与** `attrCalculator` 加算。

| 坐骑 | 占位 |
|------|------|
| 司南车 | 文人技能成功率：`0.1×L`（`getSkillMountBonus`，战斗中已实现） |
| 木牛流马 | 回合末自动回复（`processMountEndOfRound`，已实现）：`maxHp×0.001×L` 与 `maxMp×0.001×L` 取比例较低一侧回复对应资源；主将死亡无效 |
