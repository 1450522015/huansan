## 19.1 槽位与规范化

- 每单位 **4 槽**，每项 `{ 名称, 等级 }`，等级 **1–160**。  
- 空槽：`名称 == null`（或空字符串规范化后），**不参与**百分比计算。  
- 有名称槽：`等级` 越界时 clamp 到 1–160。  
- 实现见 `gameCatalog.normalize天赋项`、`天赋百分比`、`分段天赋值`。

## 19.2 效果分类（与 `docs/私有文档/天赋.md`）

1. **战斗属性（面板汇总）**  
   - **乘算**（步骤 4，对步骤 3 后的 **攻击 / 气血** 连乘）：**强攻**、**强血**。  
   - **加算**（步骤 3，与装备等同名相加）：**暴击→暴击力**、**法爆→法爆率**、**爆率→暴击率**、**反击 / 躲避 / 致命** 等。

2. **技能向（仅标记）**  
   **舍命、舍攻、合击、围困、扰乱、封锁、暗渡、夺命、风沙、妖火、落雷、毒术** 不并入上述加算层；静态结果中写入 **`天赋技能效果`**（名称→百分点），战斗逻辑使用；配置页由 **`天赋面板加成文案`** 显示摘要+百分点（如「加舍命一击伤害10%」）。**战斗属性主表不展示** `天赋技能效果`摘要行，数据仅在 JSON / API 中携带。

3. **忽视（隐藏）**  
   **忽视** 写入 **`忽视率`**（与分段表百分点一致），**不在** 战斗属性主表展示；`/api/attrs` 与本地计算结果均含该字段供战斗使用。原 **忽视→穿透率×0.5** 已取消，避免与装备穿透混淆。

详细文字说明与分段表见 [06-talents-skill-mastery.md](./06-talents-skill-mastery.md)；分类与面板文案以 `gameCatalog.js` 中 `天赋效果类别`、`天赋面板加成文案` 为准。
