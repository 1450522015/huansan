---

## 5.1 主将装备部位顺序（固定）

展示与存储顺序均为：

1. **头盔**  
2. **项饰**（原「项链」命名已废弃，导入旧 JSON 时由规范化迁移）  
3. **武器**  
4. **护腕**  
5. **铠甲**  
6. **战靴**

---

## 5.2 头盔

头盔为 **名称 + 词条** 结构；部分头盔需在多条抗性中 **任选其一**（词条），数值均为 **+10**（对应该抗性字段）。

| 名称 | 词条选项（任选其一） | 备注 |
|------|----------------------|------|
| 凤翅鎏金盔 | 抗围困、抗扰乱、抗封锁 | 三选一 |
| 绣银逍遥巾 | 抗风沙、抗妖火、抗落雷、抗毒术 | 四选一 |
| 兽骨魔神盔 | 抗物理 | 仅一项，无选择 |
| 苍云天龙冠 | 抗风沙、抗妖火、抗落雷、抗毒术 | 四选一 |

## 5.8 主将 · 装备镶嵌宝石（每部位 3 颗）

单颗宝石：`{ "属性": "<下列之一>", "数值": 1～15 }`。

**可选属性名（与代码一致）：**

体质、智力、力量、敏捷、气血、精力、攻击、防御、速度、命中率、暴击率、反击率、致命率、法爆率、反震率、躲避率、抗物理、抗玄击、抗封锁、抗扰乱、抗围困、抗风沙、抗妖火、抗毒术、抗落雷、暴击力、穿透率、爆伤力、法伤力、连击率、连击数、法穿率。

## 5.11 固定四技能（按 `角色分类`）

技能槽名称 **不可由玩家改为其他招式**；随 `角色分类` 切换时，客户端会重置为下表对应四招。

| 角色分类 | 四技能（顺序固定） |
|----------|-------------------|
| 男武 | 舍命一击、力劈华山、固若金汤、凌波微步 |
| 女武 | 舍命一击、排山倒海、固若金汤、凌波微步 |
| 男文 | 画地为牢、趁火打劫、金蝉脱壳、暗度陈仓 |
| 女文 | 画地为牢、四面楚歌、金蝉脱壳、暗度陈仓 |
| 男异 | 呼风唤雨、妖火燎原、五雷轰顶、毁天灭地 |
| 女异 | 呼风唤雨、妖火燎原、巫蛊极毒、毁天灭地 |

每槽另存 **`等级`、`熟练度`**，熟练度区间说明见 [06-天赋与技能熟练度.md](./06-天赋与技能熟练度.md)。
