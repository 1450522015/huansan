## 8.1 输出对象里有哪些字段

移动端配置页使用 **`computeAttrsFromConfig`（`common/attrCalculator.js`）** 对当前本地配置即时计算；`GET /api/attrs` 仍可对每个单位（`主将`、`副将1`～`副将3`）返回与之一致的结构（供其它客户端或调试）：

- **`风格`**：字符串，规则见 [07-属性点与风格.md](./07-属性点与风格.md)。  
- **`角色分类`**：回显配置中的值。  
- **基础战斗属性**：气血、精力、攻击、防御、速度。  
- **特殊战斗属性**：命中率、暴击率、反击率、致命率、法爆率、反震率、躲避率、抗物理、抗玄击、抗封锁、抗扰乱、抗围困、抗风沙、抗妖火、抗毒术、抗落雷、暴击力、穿透率、爆伤力、法伤力、连击率、连击数、法穿率。

（字段集合与 `common/attrCalculator.js` 中数组一致。）

## 8.2 计算流水线（概念顺序）

实现文件：**[`common/attrCalculator.js`](../../common/attrCalculator.js)**。

1. **修正四维**：`修正属性分配`（来自 `gameCatalog`）。  
2. **主将装备**：对每个部位用 **`解析装备格汇总`**（部位固定属性 + 该部位三槽宝石，同属性名相加），再跨部位累加；宝石若提供 **体质/智力/力量/敏捷**，与 **龙骨靴选敏捷** 等一并计入 **有效四维**，再代入 **主将战斗公式**（见下）。  
3. **副将**：无装备；**`宝石` 数组** 中的四维先并入有效四维，其余九抗等累加到结果。  
4. **坐骑**（仅主将）：`坐骑战斗加成(种类, 等级, 转数)`，规则见 [坐骑.md](./坐骑.md)。  
5. **主将基础战斗属性**：`等级系数(等级)` + **当前世职业轴**（`主将战斗职业轴(当前角色分类)`：武/文/异）按 [主将.md](./主将.md) 计算气血、精力、攻击、防御、速度；命中率/躲避率/暴击率/穿透率仍用原敏/力边际式（非主将文档条目）。  
6. **副将基础战斗属性**：`副将属性表` 初值取区间中点，`副将有效成长` = 成长中点 + 转数×0.1 + (星级−4)×0.05 + 真+0.05（**无双形态**的成长 + 无双等级×0.001 未计入静态面板，见 [副将.md](./副将.md)）；再按副将.md 计算血/精/攻/防/速（速度系数按当前世 武/文/异）。  
7. **天赋**：`天赋百分比(名称, 等级)` 得到百分数，再 **简化映射** 到攻击/气血/暴击率/爆伤力/法伤力等（详见代码；与 [天赋.md](./天赋.md) 分段表一致）。  
8. **副将默契度**：`副将默契战斗加成(默契度)`（见 [副将.md](./副将.md)）。  
9. **帮派能力**（仅主将）：`帮派战斗加成(主抗性, 副抗性)`，主槽 +20、副槽 +10，可只配其一或不配；都配则主≠副（见 [主将.md](./主将.md)）。  
10. **合并**：将基础、装备（非四维部分）、坐骑、天赋加成、帮派、默契等 **数值对象相加** 后取整，负数截为 0（实现中合并顺序为：基础 → 装备余量 → 坐骑 → 天赋 → 帮派 → 默契）。

## 8.3 仍为占位或可调整项

- **坐骑**：已按 [坐骑.md](./坐骑.md) 实现文档所列种类；未写入文档的列表内坐骑仍为 0 加成，扩展需同步改 `坐骑战斗加成`。  
- **主将** 文档中武人条未写「体质×20」，实现按原文；若与客户端不一致可改 `主将战斗基础`。  
- **等级系数** 使用通式 `20 + 4×⌊(L−1)/5⌋ + (L mod 5 段内偏移)`；155–160 级若需与个别旧表逐点对齐再单独校正。  
- **天赋** 到具体字段的映射（如法系伤害天赋 → `法伤力` 系数）仍为简化。  
- **无双形态内成长**（无双等级×0.001）等纯战斗内逻辑未写入静态面板；`/api/attrs` 与本地计算均含 **默契**、**帮派** 等已配置项。

保持 **输入配置结构** 与 **输出字段名** 不变，Mobile「属性」页可无缝衔接。

## 8.4 进程缓存

- **位置**：`nodejs/src/services/configCache.js`。  
- **逻辑**：以用户 ID 为键；缓存 **配置 JSON 快照** 与 **计算结果**；命中则跳过 `computeAttrsFromConfig`。  
- **失效**：`POST /api/config` 保存配置、管理端 **`PATCH` 用户密码** 等会 `invalidateUser`。
