## 8.1 输出对象里有哪些字段

`GET /api/attrs` 对每个单位（`主将`、`副将1`～`副将3`）返回 approximately：

- **`风格`**：字符串，规则见 [07-属性点与风格.md](./07-属性点与风格.md)。  
- **`角色分类`**：回显配置中的值。  
- **基础战斗属性**：气血、精力、攻击、防御、速度。  
- **特殊战斗属性**：命中率、暴击率、反击率、致命率、法爆率、反震率、躲避率、抗物理、抗玄击、抗封锁、抗扰乱、抗围困、抗风沙、抗妖火、抗毒术、抗落雷、暴击力、穿透率、爆伤力、法伤力、连击率、连击数、法穿率。

（字段集合与 `nodejs/src/services/attrCalculator.js` 中数组一致。）

## 8.2 计算流水线（概念顺序）

实现文件：**[`nodejs/src/services/attrCalculator.js`](../../nodejs/src/services/attrCalculator.js)**。

1. **修正四维**：`修正属性分配`（来自 `gameCatalog`）。  
2. **主将装备**：对每个部位调用 **`解析装备格`**，汇总攻防血精速、抗性等；装备上宝石若增加 **体质/智力/力量/敏捷**，与 **龙骨靴选敏捷** 一并计入 **有效四维**，再代入 **四维基础公式**。  
3. **副将**：无装备；仅 **`宝石` 数组**（九抗）累加到结果。  
4. **坐骑**（仅主将）：`坐骑战斗加成(种类, 等级)` → **占位公式**，见 [05](./05-装备坐骑宝石与技能表.md) 说明。  
5. **四维基础战斗属性**：由有效四维与等级经 **线性/缩放公式** 得到气血、精力、攻击、防御、速度及部分率类（**占位**，可整体替换）。  
6. **天赋**：`天赋百分比(名称, 等级)` 得到百分数，再 **简化映射** 到攻击/气血/暴击率/爆伤力/法伤力等（详见代码注释与映射表）。  
7. **合并**：数值相加后取整，负数截为 0。

## 8.3 「占位」与后续替换

以下部分 **不代表最终策划数值**，仅保证端到端可跑通：

- **坐骑战斗加成**（`gameCatalog.js`）  
- **四维 → 基础战斗属性** 的线性系数（`attrCalculator.js` 内 `四维基础`）  
- **部分天赋效果** 到具体字段的映射（如法系伤害天赋映射到 `法伤力` 的系数）

替换时建议：**只改函数体或常量表**，保持 **输入配置结构** 与 **输出字段名** 不变，Mobile「属性」页可无缝衔接。

## 8.4 进程缓存

- **位置**：`nodejs/src/services/configCache.js`。  
- **逻辑**：以用户 ID 为键；缓存 **配置 JSON 快照** 与 **计算结果**；命中则跳过 `computeAttrsFromConfig`。  
- **失效**：`POST /api/config` 保存配置、管理端 **`PATCH` 用户密码** 等会 `invalidateUser`。
