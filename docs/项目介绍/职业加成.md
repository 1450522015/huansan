## 1. 原始战斗属性

按 **战斗职业轴**（**武 / 文 / 异**）给出的 **命中率、暴击率、反击率、致命率、法爆率、反震率、躲避率** 常数。在战斗属性流水线中属于 **步骤 2「战斗基础层」**：与 [主将.md](./主将.md) 的五维公式、[副将.md](./副将.md) 的五维公式 **同时** 写入基础对象，再进入步骤 3、4。

- **主将**：轴 = `主将战斗职业轴(当前角色分类)`（当前世 `职业经历` 第四项）。  
- **副将**：轴 = 同上函数作用于 **该副将** 的 `职业经历` 第四项。  
- **性别**：男武与女武共用 **武人** 行，男文/女文共用 **文人** 行，男异/女异共用 **异人** 行。

**未列入本表** 的字段（如 **穿透率**、各类 **抗***、**暴击力** 等）基础层为 0，仅由装备、宝石、天赋、帮派、默契等在 **步骤 3** 起叠加。

## 2. 职业抗性

### 2.1 作用与配置来源

主将、副将均可拥有 **职业抗性**：由配置中的 **`职业经历` 四个槽位**（前三世 + **当前世**）逐项查表累加。界面不必单独展示「职业抗性」面板；玩家选完四次职业后，抗性即隐含确定。

- **今世**：第四槽，与战斗用 **当前世** 一致（`gameCatalog.当前角色分类` 读取 `职业经历[3]`）。  
- **前世**：第 1～3 槽，**每一槽各加一遍** 下表「前世」段（三世可同可异，同名抗性相加）。

抗性字段名与战斗面板一致：`抗物理`、`抗玄击`、`抗封锁`、`抗扰乱`、`抗围困`、`抗风沙`、`抗妖火`、`抗毒术`、`抗落雷`。

### 2.2 前世（每一槽独立加一遍）

| 该槽职业 | 抗性加成 |
|----------|----------|
| 武人 | 抗物理 +20，抗玄击 +5 |
| 男文 | 抗围困 +13，抗扰乱 +13，抗封锁 +3 |
| 女文 | 抗围困 +13，抗扰乱 +3，抗封锁 +13 |
| 男异 | 抗风沙 +12，抗妖火 +12，抗落雷 +12，抗毒术 +2 |
| 女异 | 抗风沙 +12，抗妖火 +12，抗落雷 +2，抗毒术 +12 |

### 2.3 今世（仅第四槽加一遍）

| 今世职业轴 | 抗性加成 |
|------------|----------|
| 武人 | 抗物理 +20，抗玄击 +5 |
| 文人（男文或女文） | 抗围困 +10，抗扰乱 +10，抗封锁 +10 |
| 异人（男异或女异） | 抗风沙 +10，抗妖火 +10，抗落雷 +10，抗毒术 +10 |

### 2.4 与其它来源的关系

- **帮派主/副抗性**：规则见 [主将.md](./主将.md)；与职业抗性 **不同配置项**，若接入计算器则预期为 **同名相加**。  
- **装备/宝石抗性**：见 [装备.md](./装备.md)、[05-装备坐骑宝石与技能表.md](./05-装备坐骑宝石与技能表.md)。  
- **副将职业经历**：会与主将侧性别等规则同步（`gameCatalog.sync副将职业经历性别`），**查表仍以上文为准**。

### 2.5 实现状态

**当前 V1**：`common/attrCalculator.js` **尚未** 将 §2 表格合并进 `computeAttrsFromConfig`。接入时应由 `职业经历` 四槽解析出抗性对象，在合并阶段与装备、帮派等 **按同名相加**；并同步修订 [08-战斗属性与计算说明.md](./08-战斗属性与计算说明.md)。

## 3. 前世槽位乘算加成

以下按 **第 1～3 前世槽** 各自职业，对战斗属性做 **乘算** 向加成（与 §2 抗性加法表独立）。**当前工程未写入 `attrCalculator`**，接入时需约定与步骤 3、4 的先后（例如：在加法合并之后、或与天赋乘区统一）。

| 该槽职业 | 属性加成（乘算） |
|----------|------------------|
| 武人 | 攻击力 +10% |
| 文人 | 气血 +10% |
| 异人 | 速度 +0.5% |

（多槽可同职业；若三槽均为武，则攻击乘区需约定为连乘 `(1.1)³` 还是合并为单因子，实现前请在本文补一句规则。）
