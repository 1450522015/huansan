# 影响战斗属性的因素：

## 属性点分配
战斗属性计算规则：
职业根据当前职业

武人：
气血=360+体质点✖️1.1✖️等级系数
精力=200+智力点✖️0.6✖️等级系数
攻击=80+力量点✖️1.3✖️等级系数✖️0.2
速度=10+敏捷点
防御=体质点✖️2

文人：
气血=330+体质点✖️20✖️1.1✖️等级系数
精力=280+智力点✖️20✖️1.0✖️等级系数
攻击=70+力量点✖️1.0✖️等级系数✖️0.2
速度=（10+敏捷点）✖️0.8
防御=体质点✖️2

异人：
气血=300+体质点✖️20✖️1.0✖️等级系数
精力=360+智力点✖️20✖️1.3✖️等级系数
攻击=60+力量点✖️0.7✖️等级系数✖️0.2
速度=（10+敏捷点）✖️1.1
防御=体质点✖️2

等级系数：
1至5级，分别对应20至24
6至10级，分别对应24至28
11至15级，分别对应28至32
15至20级，分别对应32至36
以此类推
95至100级，分别对应96至100
155至160级，分别对应142至148

## 帮派能力
抗物理、抗封锁、抗扰乱、抗围困、抗风沙、抗妖火、抗毒术、抗落雷  

- **主抗性**：可选一条或不选，选中则该抗 **+20 点**。  
- **副抗性**：可选一条或不选，选中则该抗 **+10 点**。  
- 可 **0/1/2 项**：都不选、只选主、只选副、或主副都选；**主副都选时两条不能相同**。  
- 配置字段：`帮派: { 主抗性, 副抗性 }`（均为上述八种之一或 `null`）。
