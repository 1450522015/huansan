## 13.1 根目录 `.env`

全仓库共享，**勿将含真实密码的 `.env` 提交到公开仓库**（若已提交需轮换密钥）。

### 前端端口与 base

| 变量 | 说明 |
|------|------|
| `VUE3_MOBILE_PORT` | Mobile 开发服务器端口 |
| `VUE3_MOBILE_BASE` | Mobile 的 `base` |
| `VUE3_ADMIN_PORT` | Admin 开发服务器端口 |
| `VUE3_ADMIN_BASE` | Admin 的 `base` |

### Node 服务（供 Vite 代理与 HTML 注入）

| 变量 | 说明 |
|------|------|
| `NODEJS_PROTOCOL` | 如 `http` |
| `NODEJS_IP` | 如 `127.0.0.1` |
| `NODEJS_PORT` | 如 `3000` |

### 数据库与安全

| 变量 | 说明 |
|------|------|
| `MONGODB_URI` | Mongo 连接串 |
| `JWT_SECRET` | JWT 签名密钥；**生产必须强随机** |

其他（Redis、Python 等）可按子项目需要扩展，见 `.env` 内注释。

---

## 13.2 本地开发推荐顺序

1. 配置 `.env`（至少 `MONGODB_URI`、`JWT_SECRET`）。  
2. 启动 MongoDB（或使用远程实例）。  
3. `cd nodejs && npm install && npm start`（或 `npm run dev`）。  
4. `cd mobile && npm install && npm start`。  
5. `cd admin && npm install && npm start`。

浏览器：

- Mobile：`http://127.0.0.1:<VUE3_MOBILE_PORT>`  
- Admin：`http://127.0.0.1:<VUE3_ADMIN_PORT>`

---

## 13.3 构建

| 项目 | 命令 | 产物 |
|------|------|------|
| mobile | `npm run build` | `mobile/dist` |
| admin | `npm run build` | `admin/dist` |

构建后的静态资源需 **配置反向代理**，将 `/api`（及 Socket.IO 路径）转发到 Node；或在构建时正确设置后端地址以便 `__BACKEND_URL__` 指向生产 API。
