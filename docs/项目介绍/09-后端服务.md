# 09 · 后端服务（Node.js）

[← 返回索引](./README.md)

---

## 9.1 入口与配置

- **入口**：`nodejs/src/index.js`  
- **环境变量**：从 **仓库根目录** `.env` 加载（`dotenv` 在 `src/config/env.js` 中指向 `../../../.env`）。  
- **常用变量**：`MONGODB_URI`、`JWT_SECRET`、`NODEJS_PORT`（或 `PORT`）、`NODE_ENV`。

---

## 9.2 中间件与横切

- **CORS**：`origin: true`，允许携带凭证。  
- **JSON body**：上限约 2MB（适配大配置）。  
- **限流**：`/api/` 下每分钟约 200 次（可按环境调整）。  
- **全局错误**：返回 `{ 错误: "服务器错误" }` 类 JSON（开发时控制台打印堆栈）。

---

## 9.3 数据模型 · 用户

**文件**：`nodejs/src/models/User.js`  
**集合名**：`users`

| 字段 | 说明 |
|------|------|
| `用户名` | 唯一，trim |
| `密码哈希` | bcrypt |
| `配置` | Mixed，完整中文 key 配置 JSON |
| `创建时间` | Date |
| `最近登录时间` | Date 或空；在 **登录成功** 时更新（注册不强制写入） |

---

## 9.4 路由模块（按前缀）

| 前缀 | 文件 | 说明 |
|------|------|------|
| `/api` | `routes/auth.js` | `POST /register`、`POST /login`（挂载在 `/api` 下，故完整路径为 `/api/register` 等） |
| `/api/config` | `routes/config.js` | JWT；读/写当前用户配置（读写前 `normalizeConfigDeep`） |
| `/api/attrs` | `routes/attrs.js` | JWT；返回计算后的属性 |
| `/api/admin` | `routes/admin.js` | **无 JWT**；用户列表分页、改密 |
| `/api/health` | `index.js` | 健康检查 |

---

## 9.5 Socket.IO

- 与 HTTP **同端口** 创建 `Server`。  
- V1：连接后推送欢迎事件；支持 `ping`/`pong`。  
- 后续可扩展：房间、用户绑定、PK 同步。

---

## 9.6 校验工具

**文件**：`nodejs/src/utils/validate.js`

- `validateCredentials`：注册/登录用户名+密码。  
- `validatePassword`：管理端改密、仅密码规则（长度与非法字符）。
