# 12 · 管理后台（admin）

[← 返回索引](./README.md)

---

## 12.1 定位

- **桌面布局**：左侧边栏 + 顶栏标题 + 主内容区。  
- **无需登录**：进入即可使用（按当前产品要求）。  
- **依赖后端**：通过开发代理或生产 `__BACKEND_URL__` 调用 Node 的 `/api/admin/*`。

---

## 12.2 页面结构

| 路由 | 说明 |
|------|------|
| `/` | 首页：说明后台用途、`.env` 与端口约定 |
| `/users` | **用户管理**：表格展示用户、登录状态标签、分页、修改密码弹窗 |

**侧边栏高亮**：按 `route.name` 区分首页与用户管理，避免父级 `/` 误高亮。

---

## 12.3 用户管理行为

- **列表**：`GET /api/admin/users?page=&pageSize=`；支持 **用户名关键词**（`keyword`）与 **登录状态**（`login`）筛选，与表格标签口径一致。  
- **界面**：页头展示总条数；筛选区与表格分区卡片化；表格悬停行、加载与空状态提示；改密为带头像缩写的弹窗。  
- **列**：用户名、注册时间、最后登录时间、**登录状态**（由 `最近登录时间` 推导：从未登录 / 今日活跃 / 7 日内 / 30 日内 / 长期未登录）。  
- **改密**：`PATCH /api/admin/users/:id/password`，body `{ "新密码": "…" }`；规则与注册密码一致。

---

## 12.4 风险与后续加固

- 任意知道 Node 地址的人可 **列用户、改密码**。  
- 建议后续：**管理端独立鉴权**、**仅内网访问**、**反向代理 + mTLS**、或 **ADMIN_API_KEY** 请求头。

---

## 12.5 环境变量（根 `.env`）

| 变量 | 作用 |
|------|------|
| `VUE3_ADMIN_PORT` | 本地 dev 端口（默认 9002） |
| `VUE3_ADMIN_BASE` | History base |
| `NODEJS_*` | Vite 代理目标 |
