本文汇总与 **职业 / 职业经历** 相关的战斗加成规格，分三块：

| 章节 | 内容 | 计算器状态 |
|------|------|------------|
| **§1 原始战斗属性** | 按 **主将 / 副将** 与 **战斗职业轴**（武/文/异）给出的命中、暴击、连击等常数，进入 **步骤 2** 战斗基础层 | **已实现**：`gameCatalog.职业原始战斗属性(轴, 是否主将)` |
| **§2 职业抗性** | 由 **`职业经历` 四个槽位**（前三世 + 今世）累加的八种抗性与今世抗性 | **主将已实现**；**副将未** 按经历合并 |
| **§3 前世槽乘算加成** | **攻击 / 气血** 按槽连乘；**速度** 倍率乘在 **先 `Math.round` 再乘** 之后（主将加算后速度、副将 `(初.速+敏)×成长`） | **已实现**：见 `主将前世槽速度连乘系数` 与 `attrCalculator` |

主将、副将均可能涉及上表；取轴、取槽规则见各节。规格以本文为准，执行以 [`common/`](../../common/) 为准，详见 [`.ai/README.md`](../../.ai/README.md)。

## 1. 原始战斗属性

按 **`docs/私有文档/职业加成.md`**：**主将今世**与 **副将今世** 各一套表；字段为 **命中率、暴击率、反击率、致命率、法爆率、反震率、躲避率、连击率、连击数**（未在私有文档列出的项为 **0**）。在战斗属性流水线中属于 **步骤 2「战斗基础层」**：与 [14-main-hero.md](./14-main-hero.md) 的五维公式、[15-deputy.md](./15-deputy.md) 的五维公式 **同时** 写入基础对象，再进入步骤 3、4。

- **主将**：`职业原始战斗属性(主将战斗职业轴(当前角色分类), true)`。
- **副将**：`职业原始战斗属性(主将战斗职业轴(当前角色分类), false)`（`当前角色分类` 取 **该副将** 配置的第四槽）。
- **性别**：男武与女武共用 **武** 轴行，男文/女文共用 **文** 轴行，男异/女异共用 **异** 轴行。

**连击数**：私有文档为 **2～3**；实现直接取 **2～3**（区间范围字符串，不取上沿）。

**未列入本表** 的字段（如 **穿透率**、各类 **抗**、**暴击力** 等）基础层为 0，仅由装备、宝石、天赋、帮派等在 **步骤 3** 起叠加。

**实现**：`gameCatalog.js` 中 `职业原始战斗属性(战斗职业轴, 是否主将)`。

## 2. 职业抗性

### 2.1 作用与配置来源

主将、副将均可拥有 **职业抗性**：由配置中的 **`职业经历` 四个槽位**（前三世 + **今世**）逐项查表累加。界面不必单独展示「职业抗性」面板；玩家选完四次职业后，抗性即隐含确定。

- **今世**：第四槽，与战斗用 **当前世** 一致（`当前角色分类` 读取 `职业经历[3]`）。
- **前世**：第 1～3 槽，**每一槽各加一遍** 下表「前世」段（三世可同可异，同名抗性相加）。

抗性字段名与战斗面板一致：`抗物理`、`抗玄击`、`抗封锁`、`抗扰乱`、`抗围困`、`抗风沙`、`抗妖火`、`抗毒术`、`抗落雷`。

### 2.2 前世（每一槽独立加一遍）

| 该槽职业 | 抗性加成 |
|----------|----------|
| 武人 | 抗物理 +20，抗玄击 +5 |
| 男文 | 抗围困 +13，抗扰乱 +13，抗封锁 +3 |
| 女文 | 抗围困 +13，抗扰乱 +3，抗封锁 +13 |

### 2.4 与其它来源的关系

- **帮派与主将抗性**：规则见 [14-main-hero.md](./14-main-hero.md)；与职业抗性 **不同配置项**；若同时接入计算器则预期 **同名相加**。
- **装备/宝石抗性**：见 [18-main-gear.md](./18-main-gear.md)、[05-gear-mount-gems-skills.md](./05-gear-mount-gems-skills.md)。
- **副将职业经历**：会与主将侧性别等规则同步（`sync副将职业经历性别`），**查表仍以上文为准**。

### 2.5 实现状态

- **主将**：`主将前世槽抗性加算`、`主将今世抗性加算` 已在 `attrCalculator` **加算层** 与装备等 **同名相加**。
- **副将**：与主将共用 `主将前世槽抗性加算`、`主将今世抗性加算`；副将 `职业经历` 已含性别前缀（如 `男文`、`女异`），查表时自动区分男/女差异。

## 3. 前世槽位乘算加成

以下按 **第 1～3 前世槽** 各自职业，对战斗属性做 **乘算** 向加成（与 §2 抗性加算表独立）。**主将、副将** 共用 `主将前世槽攻血连乘系数`、`主将前世槽速度连乘系数`；**气血与攻击的倍率**均在 **推导五维基础值时** 乘入（与主将一致）。**前世速度倍率**作用于速度前，须先将 **未乘倍率的速度** **`Math.round` 四舍五入**（主将：步骤 3 加算后的面板速度；副将：**(初.速+敏捷)×成长**），再乘 `主将前世槽速度连乘系数`（`docs/私有文档/职业加成.md`）。**速度倍率**在主将侧于加算层之后乘速度；在副将侧于 **五维公式内** 乘上述取整后的值（当前无额外速度加算来源）。

| 该槽职业 | 属性加成（乘算） |
|----------|------------------|
| 武人 | 攻击 ×1.1（每武槽连乘） |
| 文人 | 气血 ×1.1（每文槽连乘） |
| 异人 | 速度 ×1.005（每异槽连乘） |

多槽可同职业；三槽均为武时攻击倍率为 `(1.1)^3`。
