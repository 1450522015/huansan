# 07 · 属性点与风格

[← 返回索引](./README.md)

---

## 7.1 符号约定

- \(L\)：**当前等级**，范围 **1–160**，参与计算时 clamp 到此区间。  
- **四维**：`体质`、`智力`、`力量`、`敏捷`，在配置里以 **`属性分配`** 对象存储。

---

## 7.2 总点数与「空闲」

- **总点数池**（四维之和的理论上限相关）：  
  \[
  \text{等级总点} = 8 \times L
  \]
- **四维之和** 不得超过 `等级总点`。  
- **空闲**（未分配的可选点，只读展示）：  
  \[
  \text{空闲} = \text{等级总点} - (\text{体质}+\text{智力}+\text{力量}+\text{敏捷})
  \]
  在数据合法时，空闲 ≥ 0。

---

## 7.3 每项下限与「可选点池」

- **每项下限**：四维各自 **≥ \(L\)**（即每个维度至少有「当前等级」点底数）。  
- **四维之和最小值**：\(4L\)（当四项都取最小值时）。  
- **可选点池**（可自由分配到四维上的额外点数上限）：  
  \[
  \text{可选点上限} = 4 \times L
  \]
  当四维均等于 \(L\) 时，四维和为 \(4L\)，空闲为 \(8L - 4L = 4L\)，与可选点池一致。

**理解**：\(8L\) 中有一半 \(4L\) 是「锁在每项至少 \(L\)」的底数，另一半 \(4L\) 可由玩家在四维上自由分配；**空闲** 即这 \(4L\) 中尚未花掉的部分。

---

## 7.4 降等级与溢出重置

当 **等级降低** 或数据异常导致 **四维之和 > 8L** 时，实现上执行 **`修正属性分配`**：

- 将 **四维全部重置为** \(\{体质: L,\ 智力: L,\ 力量: L,\ 敏捷: L\}\)。

（与 `docs/当前任务.md` 中「降低等级后点数超出则恢复默认值」一致。）

---

## 7.5 风格判定（仅看「可选点」分配）

先对 **`属性分配`** 做 **`修正属性分配`**，再定义每项 **超出底数 \(L\) 的可选增量**（与 7.3 中「每项至少 \(L\)」一致）：

\[
e_{体} = \max(0,\ 体质 - L),\quad
e_{智} = \max(0,\ 智力 - L),\quad
e_{力} = \max(0,\ 力量 - L),\quad
e_{敏} = \max(0,\ 敏捷 - L)
\]

**规则**（实现为 `计算风格`）：

1. 将 **血**（体质）、**精**（智力）、**攻**（力量）、**速**（敏捷）与各自的 \(e\) 组成四元组。  
2. 按 **\(e\) 从大到小** 排序；**\(e\) 相同** 时按固定优先序 **体质 → 智力 → 力量 → 敏捷**（即血 → 精 → 攻 → 速）。  
3. 记排序后第一、第二名的可选增量为 \(e_1\)、\(e_2\)。  
   - **仅第一名配了可选点**（\(e_1>0\) 且 \(e_2=0\)）：只认第一名对应维度，风格为 **气血型 / 精力型 / 攻击型 / 速度型** 之一（分别对应体质 / 智力 / 力量 / 敏捷）。  
   - **其余情况**（包括「前二 \(e\) 均为 0」或「前二 \(e\) 都大于 0」）：仍取排序后 **前两名简称** 拼成双字风格名，例如血、精 → **血精型**；全未分配时 \(e\) 全为 0，前二为血、精 → **血精型**。
