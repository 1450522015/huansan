# 07 · 属性点与风格

[← 返回索引](./README.md)

---

## 7.1 符号约定

- \(L\)：**当前等级**，范围 **1–160**，参与计算时 clamp 到此区间。  
- **四维**：`体质`、`智力`、`力量`、`敏捷`，在配置里以 **`属性分配`** 对象存储。

---

## 7.2 总点数与「空闲」

- **总点数池**（四维之和的理论上限相关）：  
  \[
  \text{等级总点} = 8 \times L
  \]
- **四维之和** 不得超过 `等级总点`。  
- **空闲**（未分配的可选点，只读展示）：  
  \[
  \text{空闲} = \text{等级总点} - (\text{体质}+\text{智力}+\text{力量}+\text{敏捷})
  \]
  在数据合法时，空闲 ≥ 0。

---

## 7.3 每项下限与「可选点池」

- **每项下限**：四维各自 **≥ \(L\)**（即每个维度至少有「当前等级」点底数）。  
- **四维之和最小值**：\(4L\)（当四项都取最小值时）。  
- **可选点池**（可自由分配到四维上的额外点数上限）：  
  \[
  \text{可选点上限} = 4 \times L
  \]
  当四维均等于 \(L\) 时，四维和为 \(4L\)，空闲为 \(8L - 4L = 4L\)，与可选点池一致。

**理解**：\(8L\) 中有一半 \(4L\) 是「锁在每项至少 \(L\)」的底数，另一半 \(4L\) 可由玩家在四维上自由分配；**空闲** 即这 \(4L\) 中尚未花掉的部分。

---

## 7.4 降等级与溢出重置

当 **等级降低** 或数据异常导致 **四维之和 > 8L** 时，实现上执行 **`修正属性分配`**：

- 将 **四维全部重置为** \(\{体质: L,\ 智力: L,\ 力量: L,\ 敏捷: L\}\)。

（与 `docs/当前任务.md` 中「降低等级后点数超出则恢复默认值」一致。）

---

## 7.5 超出可选池的「纯风格」判定

定义 **超出量**（在每项已至少为 \(L\) 的前提下）：

\[
e_{体} = \max(0,\ 体质 - L),\quad
e_{智} = \max(0,\ 智力 - L),\quad
e_{力} = \max(0,\ 力量 - L),\quad
e_{敏} = \max(0,\ 敏捷 - L)
\]

记 **可选点上限** \(O = 4L\)。

若 **全部可选点** 都加在 **单一维度**（其余维度超出量为 0），则风格为：

| 条件 | 风格名 |
|------|--------|
| \(e_{体} \ge O\) 且 \(e_{智}=e_{力}=e_{敏}=0\) | **气血型** |
| \(e_{智} \ge O\) 且 \(e_{体}=e_{力}=e_{敏}=0\) | **精力型** |
| \(e_{力} \ge O\) 且 \(e_{体}=e_{智}=e_{敏}=0\) | **攻击型** |
| \(e_{敏} \ge O\) 且 \(e_{体}=e_{智}=e_{力}=0\) | **速度型** |

---

## 7.6 混合分配：双维风格

若不属于上述「纯型」，且 **\(e_{体}+e_{智}+e_{力}+e_{敏}=0\)**（即未使用任何可选点），风格为 **混合型**。

否则：将 \((体质,e_{体}),(智力,e_{智}),(力量,e_{力}),(敏捷,e_{敏})\) 按 **\(e\) 从大到小** 排序，取 **前两名** 对应的两个维度，按下表映射：

| 前两维（无序） | 风格名 |
|----------------|--------|
| 体质 + 智力 | **血精型** |
| 力量 + 敏捷 | **攻速型** |
| 体质 + 力量 | **血攻型** |
| 体质 + 敏捷 | **血速型** |
| 智力 + 力量 | **精攻型** |
| 智力 + 敏捷 | **精读型** |
| 其他组合 | **混合型** |

---
