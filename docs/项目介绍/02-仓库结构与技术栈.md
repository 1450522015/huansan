## 2.1 顶层目录树（与职责）

```text
huansan/
├── .env                    # 全仓库共享环境变量（各子项目通过 Vite/Node 读取）
├── data/
│   └── gameCatalog.js      # 游戏静态表 + 配置规范化 + 属性点/风格计算（Node + Mobile 共用）
├── docs/                   # 需求、任务、本「项目介绍」系列
├── nodejs/                 # Express + Mongoose + Socket.IO 主服务
├── mobile/                 # Vue3 + Vite + Capacitor 手游
├── admin/                  # Vue3 + Vite 管理后台（桌面布局）
└── python/                 # 预留（AI 等）
```

## 2.2 子项目技术栈

### mobile（手游）

- **框架**：Vue 3（Composition API / `<script setup>`）  
- **构建**：Vite 5  
- **路由**：Vue Router（Hash 模式，便于静态部署与 Capacitor）  
- **状态**：Pinia（已挂载，可按需使用）  
- **HTTP**：Axios（开发期通过 Vite 代理访问 Node）  
- **实时**：Socket.IO Client（Shell 布局内连接，用于后续扩展）  
- **原生壳**：Capacitor（Android 等）

**路径别名**：`@` → `mobile/src`；`@data` → 仓库根目录 `data/`（与 Node 共用 `gameCatalog.js`）。

### admin（管理后台）

- **框架**：Vue 3  
- **构建**：Vite 5  
- **路由**：Vue Router（History 模式，`base` 来自 `.env` 的 `VUE3_ADMIN_BASE`）  
- **HTTP**：Axios，`/api` 代理到 Node（开发期）

**特点**：**全局无登录**（按当前产品要求），仅建议在可信网络使用。

### nodejs（主后端）

- **运行时**：Node.js（ES Module，`"type": "module"`）  
- **HTTP**：Express 4  
- **数据库**：MongoDB + Mongoose 8  
- **鉴权**：JWT（`jsonwebtoken`），用于 **Mobile** 用户接口  
- **密码**：bcryptjs  
- **实时**：Socket.IO 4  
- **限流**：`express-rate-limit`（`/api/` 前缀）

### data/gameCatalog.js

- **语言**：JavaScript（ESM），**零构建**即可被 Node 直接 `import`。  
- **被引用方**：`nodejs/src/services/*`、`mobile` 通过 Vite alias `@data`。  
- **人类可读规格**：见本目录 [05](./05-装备坐骑宝石与技能表.md)、[06](./06-天赋与技能熟练度.md)、[07](./07-属性点与风格.md) 及 [03](./03-共享规则与代码对照.md)。
