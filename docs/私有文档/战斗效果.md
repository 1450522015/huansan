# 普通攻击、暴击攻击、忽视攻击、致命攻击

这四种攻击的效果一样，以暴击攻击举例说明
例如 a 攻击 b
1、a亮蓝框，b亮红框，同时横幅显示：暴击攻击
2、速度×1时间隔2秒，速度×2时间隔1秒，速度×3时间隔0.5秒，无动画间隔0秒
3、双方各自做出对应的数据变化，例如气血精力速度变化，包括buff变化，包括死亡，
4、速度×1时间隔2秒，速度×2时间隔1秒，速度×3时间隔0.5秒，无动画间隔0秒
5、双方边框熄灭，横幅数据消失
