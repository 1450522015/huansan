# 技能

技能，每个将最多有4个技能
技能是单体时，出招阶段直接选中目标即可，技能是群体时，也是只能选中一个目标，然后由群体中速度高的先接招
（例如对敌技能，选中对方速度4号位，技能目标数时3，那么就指向敌方速度4号位、速度2号位、速度1号位，同理，群体技能是对己方使用时也是如此）
舍命一击，武人专属，单体，伤害取决于自身攻击力、天赋、穿透率，和对方的物理抗性
力劈华山，男武专属，单体，伤害取决于对方的最大生命值，和对方的玄抗
排山倒海，女武专属，对敌方3人造成伤害，伤害取决于对方的最大生命值，和对方的玄抗
固若金汤，武人专属，对己方4人施加buff，buff简称“固”，持续6回合，提升己方所有抗性
凌波微步，武人专属，对己方4人施加buff，buff简称“速”，持续6回合，提升己方速度
画地为牢，文人专属，对敌方3人施加buff，buff简称“围”，持续6回合，中招后不能使用攻击、技能，可以使用招将、物品
趁火打劫，男文专属，对敌方1人施加buff，buff简称“乱”，持续6回合，中招后无法行动，并随机攻击场上一个目标
四面楚歌，女文专属，对敌方1人施加buff，buff简称“封”，持续6回合，中招后无法行动，（注意注意，即使受到了围乱封，也可以出招，如果轮到自己行动时，自己还是被困状态，那也就是自己选的行动失效而已）
金蝉脱壳，文人专属，对己方1人，解除文人buff，（注意注意，因为双方都出招后，是按速度排名，依次行动的，如果己方速度1号位被围乱封，那么它本回合肯定无法行动，
但如果是己方速度4号位被围乱封，己方速度3号位对己方速度4号位使用了金蝉脱壳，并成功打出效果，那己方速度4号位本轮是可以出招的，因为轮到它行动时自身是自由状态）
暗渡陈仓，文人专属，对己方4人施加buff，buff简称“隐”，持续6回合，成功后对方无法看到自身的血量和精力
呼风唤雨，异人专属，对敌方4人造成火属性伤害，伤害会被对方的抗风沙给格挡一部分
妖火燎原，异人专属，对敌方4人造成火属性伤害，伤害会被对方的抗妖火给格挡一部分
五雷轰顶，男异专属，对敌方1人造成雷属性伤害，伤害会被对方的抗落雷给格挡一部分
巫蛊极毒，女异专属，对敌方4人造成毒属性伤害，并对敌方4人施加buff，buff简称“毒”，伤害会被对方的抗毒术给格挡一部分
毁天灭地，异人专属，对敌方1人施加buff，简称“毁”，3回合后生效，对目标造成雷属性伤害，对其它目标造成火属性伤害，如果buff生效前目前死亡或者施法人死亡，buff失效

所有技能的伤害最小值，都是1，且都是整数（要四舍五入）

关于各种各样的天赋增幅以及神将技增幅，没有就是0

没强调目标个数的，就是单体攻击，

多目标技能，只用选中一个敌方单位即可，由对方速度最高的单位吃技能，
例如，3目标技能，敌方4人，选中的是敌方速4，那后台计算技能时，直接包含对方的速1和速2，且三个目标受到同等效果，
排山倒海和毁天灭地技能除外，都有单独描述

所有的buff型技能，如果施法时，对方身上已经有了同类buff，此次施法无效，
例如凌波微步技能，buff简称“速”，持续5回合，当还剩3回合时再次施加速buff，无效，身上的速buff还是剩余3回合

在主将副将配置页的技能处，显示当前效果，例如（当前效果：39000）

注意：保留2位小数的技能：力劈华山、排山倒海、固若金汤、凌波微步、画地为牢、趁火打劫、四面楚歌、金蝉脱壳、暗渡陈仓
其它技能四舍五入为整数

所有对敌技能，当行动时发现目标已死亡（包括主将气血值为0），则选中目标自动切换为对方速度最快的单位，
同理，所有对己技能，当行动时发现目标已死亡（包括主将气血值为0），则选中目标自动切换为己方速度最快的单位，

关于buff回合数
固、速、围、乱、封、隐，都是6回合，其中施展技能的回合就已经是第1回合了，第6回合时buff存续的最后一回合，
此时对目标施加同样的buff是无效的，因为此时同名buff还在，不影响当前buff的效果，还是下一回合消失，
buff是第7回合刚开始的时候就消失的（如果buff存续期间没有被打断的话，正常度过了完整的生命周期），前端在第7回合出招前能看到buff消失，

关于巫蛊极毒buff的回合数
根据技能等级判断回合数，例如满级，6回合，施展技能的回合就已经是第1回合了，第6回合时buff存续的最后一回合，
由于毒buff是在回合开始前生效，所以第6回合虽然会受到毒发伤害，但是看不到毒buff，因为此回合出招阶段的时间点，毒buff已经结束了，
和其它buff不同的是，当目标身上已经有毒buff时，施展巫蛊极毒同样会生效，并且两次毒的伤害各自独立计算，可以叠加，毒发时受到多个毒buff的共同伤害，

关于毁天灭地buff的回合数
3回合后生效，准确来说其实是第4回合生效（3回合后就是第4回合），施展技能的回合是第1回合，
此时对目标施加同样的buff是无效的，并且buff存续期间，如果施法者或者目标死亡（包括主将气血值为0），buff会失效消失，
由于毁buff是在回合开始前生效，所以第4回合虽然会受到爆炸伤害，但是看不到毁buff，因为此回合出招阶段的时间点，毁buff已经结束了，
注意：回合开始前计算数据时，先显示毒发，再显示毁发，但其实是同时，因此如果此时毒发导致毁buff发起者死亡，毁buff依然能爆炸

关于围乱封buff
如果成功标记了buff，buff上标记上成功时的成功率，buff存在的第2回合开始前，再次判断成功率，如果不成功，则buff解除，如果成功，则buff持续到6回合
例如第1回合，我方速3成功控制了对方速1，第2回合开始前再次判断成功率时失败，那就意味着对方的行动完全没有受到影响，因为第1回合对方也正常行动了，
例如第1回合，我方速1成功控制了对方速3，第2回合开始前再次判断成功率时失败，那就意味着只控制了对方1回合，因为第1回合对方的行动被限制了，

关于围乱封buff
乱和封可以覆盖围，例如目标身上有“围”buff，不管当前的围buff已经持续到了第几回合，成功（失败的话不覆盖）施加封乱buff后，原来的围buff消失
乱和封可以互相覆盖，例如目标身上有“乱”buff，不管当前的乱buff已经持续到了第几回合，成功（失败的话不覆盖）施加封buff后，原来的乱buff消失，乱覆盖封也是同理
围不能覆盖封乱，例如目标身上有封乱buff，直接认定围buff不成功，无法覆盖施加
总结：同一目标，围乱封只会出现1个，封乱可以覆盖围，封乱可以互相覆盖，围不能覆盖封乱
