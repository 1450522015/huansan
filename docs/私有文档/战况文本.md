# 战况-系统
给开发人员看的，追求详细
1、行动失败的和防御显示
2、攻击类型，不仅显示发起者、目标、攻击类型，
还要显示原伤害（用公式计算出来的）和原浮动伤害（计算了攻击浮动后的）和实际伤害（计算了防御和抗性之后的）
3、伤害型技能，不仅显示发起者、目标，还要显示原伤害和实际伤害
4、文人buff型技能，不仅显示发起者、目标、结果，还要显示原成功率和实际成功率
5、武人buff型技能，不仅显示发起者、目标，还要显示buff效果值

# 战况-用户

给用户看的，追求简洁
1、行动失败的和防御的不显示
2、攻击类型（普通攻击、特殊攻击），显示攻击类型和造成的伤害即可
例如：速武(电脑)-(真)金·马超 普通攻击 729-(真)金·马超 -4921
3、伤害型技能，显示发起者和目标和造成的伤害即可
4、buff型技能，显示发起者和对每个目标造成的结果即可
