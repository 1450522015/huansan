# 战斗系统

双方刚进入战局后，来到第1回合

每回合起始时，后台都要计算一遍速度排名，
例如场上8个人物（小于等于8个），速度分别是200、300、400、500、600、812、800、800，
排序时，规则1是按速度值从小到大排名，规则2是当两个速度值的差距小于20时，引入随机概率，
当自身速度是100，对方速度是100，相等，自身排名靠前的概率就是50%，
当自身速度是90，对方速度是100，小10，自身排名靠前的概率就是25%，
当自身速度是80，对方速度是100，小0，自身排名靠前的概率就是0%，
也就是速度跟对方相比，差距在-20至20之间时，自身速度排名更高的概率为0%至100%线性递增
只有在场的人才有速度排名，主将死亡时，主将还在场，只是气血值为0，参与速度排名，
副将死亡时，副将被清出场地，不在场了，下一回合就不参与速度排名了

目前页面上显示的，就是战局中可以看到对方的所有数据

然后双方各自，在9999秒内选择出招，后台计时，双方都出招结束，或者超时（那就按自动来算）

自动：自动就是选择攻击，目标是对方阵营速度最快的那个

出招，参考 docs/私有文档/战斗操作.md

然后后台根据本轮速度排行，逐个出招，
注意注意：每次有单位使用凌波微步技能，都要重新计算一次速度排行，
例如我方速1使用凌波微步，速度排行重新计算后，我方速3变成了速2，那么接下来应该由我方速2出招

有可能轮到副将1出招时，它已经死亡了（死亡就是气血值为0，气血值是非负整数），那它就没办法出招，
使用物品，九转丹，可以恢复气血值，是立即生效，例如速1给速8回血，速2攻击速8时，速8的气血值是吃药之后的，
副将死亡时，无法被物品复活，页面上对应位置留空即可，不整理布局，
主将死亡时，框还在，显示气血值为0，可以被物品复活，
例如，速1击杀了我方速8主将，我方速7给主将使用加气血的物品，主将会复活，轮到速8主将出招时一样能正常出招，
并且，主将即使死亡，也能被喂精力物品，例如速1给速8主将喂精力，速8的精力值会增加，即使此时主将已死亡，
主将死亡后，身上的buff全部失效，即使本回合就被救活，也是无buff状态，
例如，主将身上本来有一堆buff，但是速1击杀了速8主将，己方速2复活（使用物品，九转丹，给主将）了速8主将，
然后对方的速3用攻击或者技能针对我方速8主将，此时主将身上已经没有buff了，要注意计算，

关于出招时的ui，按顺序，主将出招、副将1、副将2、副将3出招，
出招前，也就是轮到当前单位出招了，当前单位的方框显示绿色，然后点击操作面板上的任意选项，
这些选项的操作类型一共分为三类，指向对方一个单位，指向己方一个单位，无指向，
如果是无指向，选完操作面板就可以把绿色边框让给下一个出招单位了，全部出招完，边框都不亮，就等着对方或者后台操作了，
如果是有指向，此时在横幅（双方名称和双方主将之间，有一个显示单行文本的横幅）上，
显示“请选择对方目标”，或者“请选择己方目标”，选完，就该下一单位出招了，

整个出招动作，都是前端完成，自身所有单位出招结束后，统一把操作数据提交到后台，
如果因为下线等原因，没有按时把操作提交到后台，那后台就按该用户选了自动来算，

目前页面上有个自动攻击按钮，出招阶段点击后，剩余操作都按自动来算，
自动就是选择攻击，目标是对方阵营速度最快的那个单位，
例如用户已经给主将指定了出招，然后点了自动，那主将的出招还按用户的来，其它单位的出招就填充为攻击对方速度最快的单位，

自动攻击是前端在前端填充具体操作数据，后端接收到的是完整的出招数据（每个单位的操作和目标都已明确），后端不需要判断是否是自动。

全部计算完后，后台把每一步的操作，发到前端，显示到聊天框中
然后进入新的回合，直到一方全部倒下，逃跑，或者双方都下线

# 操作面板

可选项：攻击、技能、招将、物品、防御、逃跑

注意：
所有概率事件，都由后台系统随机生成，玩家无法控制
本文提到的属性等名词，都是指玩家的属性。如果是想指代对方的属性，我会加上“对方”前缀

# 1.攻击

详见 攻击.md

# 2.技能

暂不开发，暂不能点击

# 3.招将

每个人的主页，最多配置10名副将，其中最多3名已战，
在战局过程中，只有主将可以选择招将，从剩余的副将中任选其一，
1、如果主将行动时，主将死亡，或者被"封"，或者被“乱”，则无法招将，
2、需要满足 队伍搭配.md 中的条件，否则无法招将，
战局中，副将死亡后，空出位置用于招将，并且该副将在当前战局内属于已死亡，无法再被招将

# 4.物品

只有两个选项，九转丹，龙涎露
使用目标是己方任意目标，可以是自己，单体，
如果发起方行动时，自身死亡，或者被"封"，或者被“乱”，则无法使用物品，
如果是九转丹，目标会恢复100%的气血，主将死亡时可以被复活，副将死亡时无法被使用
如果是龙涎露，目标会恢复100%的精力，主将死亡时依然可以给主将回复精力，副将死亡时无法被使用

# 5.防御

主将和副将都可以发起防御，防御就是什么都不做，相当于没有任何行动，轮空，
